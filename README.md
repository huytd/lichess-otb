# lichess-otb

Browser-only webcam chessboard recognition: point a webcam at a physical board
(camera at one player's end), and the app tracks the game move by move using a
YOLO piece detector running in the browser. Export to PGN or lichess analysis.
No server, it runs entirely client-side.

Status: design phase. See [docs/DESIGN.md](docs/DESIGN.md).
